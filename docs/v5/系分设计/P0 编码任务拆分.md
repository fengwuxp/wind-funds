# 二、拆分原则

1. 先补能发现资金错误的测试，再调整结构。
2. 先保护账本主链路，再迁移交易门面。
3. 先让字段和契约显式，再收敛 helper 和字面量。
4. 每个任务必须有验收测试和本地验证命令。
5. 不把完整清结算批处理、归档落表和完整 Fx 运营对象混入第一批 P0 代码；但错币种红线、余额控制无 FX、余额变更观察口子和结算策略表达式契约必须作为 P0 回归闸口先闭合。

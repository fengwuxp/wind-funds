# 收单业务设计入口

> 归档说明：本目录为收单业务早期预研材料。当前收单业务权威口径以 `docs/产品设计/08-收单业务资金底座PRD.md`、产品边界能力图、系分设计和 TDD 设计为准；本目录不作为编码准入或生产交付依据。

## 1. 定位

本目录用于承接“未来可能支撑收单业务”这一不确定业务模式下的产品架构、系统边界、落地计划和图形化设计。

当前结论：

1. `wind-funds` 不直接成为完整收单产品、支付网关、商户入网系统、通道协议系统或 PCI 敏感数据系统。
2. `wind-funds` 支撑收单业务产生后的资金底座能力，包括资金事实、账户余额、账本分录、清结算、对账、结算出款、争议资金影响、投影、归档和重放。
3. 业务模式、法域、主体资质、卡组织或 PSP 规则未确认前，本目录只作为设计输入和未来批次准入材料，不作为编码授权。

## 3. 使用方式

本目录不替代既有 `docs/产品设计`、`docs/DSL设计`、`docs/系分设计`、`docs/TDD设计` 和 `openspec` 权威基线。后续如果确认进入收单支撑批次，应先把本目录结论评审通过，再按项目准入规则决定是否同步回主权威文档和 OpenSpec。

进入编码前至少需要补齐：

1. 收单业务模式和主体角色。
2. 法域、资质、资金归属和外部规则确认状态。
3. 是否只接收外部收单事件，还是在本仓库新增收单应用层模块。
4. 清结算、对账、争议、结算出款和归档重放的测试矩阵。
5. 独立 OpenSpec change、Execution Grant、允许写入范围和验证命令。

# 设计预研归档

本目录保存早期设计评估、业务预研和已被主线设计吸收的历史材料。当前权威入口仍然是 [../../README.md](../../README.md) 以及产品设计、DSL 设计、系分设计、TDD 设计和用户接入指南。

历史原文保留在本目录中，便于后续追溯“为什么形成资金底座 + 场景交易能力包 + 外部系统边界”的产品和系统判断。阅读时先看 [历史预研摘要.md](历史预研摘要.md)，再按需打开原文；不得反向用归档原文覆盖当前权威设计。

## 使用边界

1. 本目录不作为当前 PRD、DSL、系分、TDD 或用户接入指南的权威口径。
2. 本目录不授权新增代码、测试、DDL、公共 API、枚举、状态机或生产配置。
3. 本目录中的能力成熟度和阶段性判断可能已经过期；需要交付或编码时，以当前权威设计包和最新实现复核为准。
4. 如本目录与当前权威设计包冲突，以当前权威设计包为准，并优先修正权威设计包或更新归档说明。

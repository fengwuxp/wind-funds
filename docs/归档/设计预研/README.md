# 设计预研归档

本目录保存早期设计评估、业务预研和已被主线设计吸收的过程材料。当前权威入口仍然是 [../../README.md](../../README.md) 以及产品设计、DSL 设计、系分设计、TDD 设计和用户接入指南。

## 使用边界

1. 本目录不作为当前 PRD、DSL、系分、TDD 或用户接入指南的权威口径。
2. 本目录不授权新增代码、测试、DDL、公共 API、枚举、状态机或生产配置。
3. 本目录中的能力成熟度、现状判断和任务基线可能已经过期；需要交付或编码时，以当前权威设计包和最新实现复核为准。
4. 如本目录与当前权威设计包冲突，以当前权威设计包为准，并优先修正权威设计包或更新归档说明。

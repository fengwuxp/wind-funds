# 设计归档

本目录保存已经被当前权威设计包吸收、替代或降级为历史背景的材料。归档原文可以保留，用于追溯设计来源、评审讨论和后续专项重启时的背景理解；摘要文档用于快速定位稳定结论和当前承接入口。

归档材料不作为 PRD、DSL、系分、TDD、工程准入、编码授权或生产交付的判断依据。评审或宣讲需要引用归档材料时，必须回到 [../README.md](../README.md) 中列出的权威设计包核对当前口径。

| 子目录 | 内容 | 使用边界 |
| --- | --- | --- |
| [设计预研](设计预研/README.md) | 早期三类业务、收单边界和上层订单交易边界的历史预研原文与摘要。 | 只作为历史背景和设计来源说明，不直接指导编码、测试或上线。 |

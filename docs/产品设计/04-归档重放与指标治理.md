# 资金数据治理拆分索引

## 1. 调整结论

本文件不再作为独立 PRD 分册承载完整“归档重放与指标治理”能力。产品层将“归档”降级为事实留存、冷热位置变化和治理证据，不再把它设计成面向用户或运营的一等产品能力。

原 04 内容已拆入 02、03 和 05：

| 原内容 | 新承接位置 | 产品口径 |
| --- | --- | --- |
| 资金事实归档、Manifest、冷热对象清单。 | 05 产品验收与 TDD 用例矩阵。 | 作为事实留存和审计证据，不改变交易、账本或分录身份。 |
| 余额检查点、余额水位、余额快照、余额重建。 | 02 交易路由钱包账目与投影的余额投影章节，05 的 `AC-ARCH-*`。 | 作为账本余额可重建能力，不成为新的余额事实源。 |
| 交易投影重放、支付工具流水、账户流水、预算和规则视图。 | 02 交易路由钱包账目与投影的交易投影章节，05 的 `AC-REPLAY-*`。 | 只重建账单、流水和时间线，不反写交易、路由、账本或余额。 |
| 清分、清算、结算、出款和对账差异的批次视图重放。 | 03 清结算与对账，05 的 `AC-REPLAY-004`。 | 只修复批次展示、导出和差异视图，不重新清分、清算、出款或入账。 |
| 指标项输入、报表数仓、大数据消费和指标水位边界。 | 05 的 `AC-RPT-*`、`GOV-GATE-007`、`GOV-GATE-009`。 | 只提供只读、脱敏、可审计输入，不计算正式报表指标，不推进资金水位。 |
| 历史预研、阶段性归档材料。 | `docs/归档/`。 | 仅作设计演进背景，不作为当前 PRD、DSL、系分、TDD 或编码授权依据。 |

## 3. 保留本文件的原因

当前仓库、OpenSpec、TDD 设计和图形化产物仍存在指向 04 的历史链接。为了避免一次性删除导致评审入口断裂，本文件暂时作为兼容索引保留。

保留期间的规则：

1. 新增余额检查点、水位、余额快照和余额重建内容时，写入 02 和 05。
2. 新增交易投影重放、支付工具流水、预算或规则视图重放内容时，写入 02 和 05。
3. 新增清结算批次、对账差异和批次视图重放内容时，写入 03 和 05。
4. 新增指标输入、数仓消费、治理导出、指标水位或大数据边界内容时，写入 05，并在 DSL、系分或 TDD 中承接。
5. 本文件只维护拆分映射，不再维护完整对象模型、流程图、状态机、规则矩阵或工程门禁。

## 4. 移除判定

当以下条件全部满足后，可以删除本文件：

| 条件 | 判定方式 |
| --- | --- |
| 产品 README 不再把 04 作为正式阅读分册。 | 目录只保留 02、03、05 的治理承接入口。 |
| OpenSpec、TDD、DSL 和系分的引用不再依赖 04 文件路径。 | `rg "04-归档重放与指标治理|归档重放与指标治理"` 无权威入口引用。 |
| 图形化产物已重命名或迁移说明已落地。 | `big-data-archive-replay-flow.svg` 不再作为 04 正文配图。 |
| 05 已完整承接 `GOV-GATE-*`、`AC-ARCH-*`、`AC-REPLAY-*`、`AC-RPT-*`。 | 验收矩阵、TDD 和 OpenSpec 能独立说明治理准入。 |

删除前仍需做一轮产品、系分、DSL、TDD 和 OpenSpec 引用检查，避免外部评审材料出现断链。
